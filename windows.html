Windows 3.0.0 · aplicativo nativo para Windows 10/11 x64

BAIXAR PARA WINDOWS · 54 MB
Como instalar
  1. Extraia todo o ZIP para uma pasta.
  2. Abra GUHFLIX.exe, mantendo as duas DLLs junto dele.
  3. Entre com a mesma conta de cliente ativa usada na TV.

São até 3 reproduções simultâneas por conta entre PCs e TVs. Cada vídeo da multitelas conta separadamente.

Validação

Testes nativos Windows, incluindo DPAPI, e testes da API de assinatura e concorrência passaram. O login e o bloqueio foram exercitados também na interface nativa em ambiente Linux de teste. Reprodução real, GPU, áudio e legendas ainda precisam de validação no seu PC. Não foi fornecida assinatura Authenticode.

O servidor pode precisar iniciar após inatividade; aguarde a tela de conexão. Dados antigos SaimoTV permanecem intactos. A nova pasta é %APPDATA%\GUHFLIX.
