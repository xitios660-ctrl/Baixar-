# Instalar GUHFLIX na TCL

1. Transfira GUHFLIX-TV.apk para a TV por USB ou ferramenta de envio de arquivos de sua confiança.
2. Abra o APK no gerenciador de arquivos. Se solicitado, autorize a instalação somente para esse instalador.
3. Confirme Instalar e abra GUHFLIX na lista de aplicativos da TV. Saimo TV e TV DO GUH AI podem permanecer instalados.
4. Aguarde a abertura ou pressione OK para pular. Use setas e OK para navegar; Voltar retorna.
5. Configure no GUHFLIX suas fontes e contas autorizadas, se necessário. Os dados do aplicativo original não são importados automaticamente.
6. Valide um filme, uma série e a troca de episódio antes de usar como aplicativo principal. Esta versão ainda não foi executada na TCL.

Se o Android bloquear a instalação, registre a mensagem completa para verificar assinatura, compatibilidade e reputação. Não é necessário desativar o Play Protect como parte destas instruções. Para remover, use Configurações > Aplicativos > GUHFLIX > Desinstalar; isso remove seus dados locais.

Instalação opcional por ADB já autorizado: `adb install GUHFLIX-TV.apk`. Não é preciso root nem ativar depuração para instalar por arquivo.
