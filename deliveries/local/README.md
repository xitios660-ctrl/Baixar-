- Código compilado: `e2987ee`. Os arquivos da interface no APK são idênticos aos da fonte.
- 38 testes Android e 5 testes de interface passaram. Instalação e reprodução reais na TCL ainda pendem de teste físico.
- Pacote separado: não atualiza o anterior nem transfere automaticamente seu histórico. Dados anteriores preservados. Esta edição não aplica assinaturas ou limite de telas e não participa do OTA de produção.
