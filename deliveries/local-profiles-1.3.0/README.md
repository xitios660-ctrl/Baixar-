# Gfilmes Local 1.3.0 — perfis sem senha

Instalar por cima de **Gfilmes Local**, sem desinstalar nem limpar dados. Mesmo pacote `com.gfilmes.tv.local`; versão 1.3.0, código 1003000, Android 6.0+, chave de assinatura original. Abrir o ícone **Gfilmes Local**.

Escolher **Quem vai assistir?** → uma pessoa. Para adicionar alguém: **Criar perfil** → nome → avatar → salvar. **Gerenciar perfis** permite renomear, trocar avatar ou excluir, com confirmação. Nenhum perfil exige PIN ou senha. O PIN antigo é retirado preservando IDs, nomes e bibliotecas; não é preciso lembrar a senha antiga.

Cada pessoa tem seu próprio Continue assistindo, favoritos e progresso nesta instalação. Foram corrigidos o retorno atrasado de outro perfil e o salvamento tardio de player após troca. Sem API de contas ou autorização por TV. Internet continua necessária para as fontes de conteúdo online. Não há sincronização de perfis entre televisões.

43 testes JVM e 9 Chromium passaram. Os dados da prévia e dos testes de interface são fictícios e não representam clientes criados no MongoDB. A reprodução/instalação na TCL e o salvamento real do ExoPlayer ainda precisam de teste físico.
